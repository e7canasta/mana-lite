El sistema **mana-lite** es una infraestructura de visión computacional de alto rendimiento diseñada para el análisis de video en tiempo real mediante flujos RTSP. Su arquitectura se organiza como un **pipeline lineal en Rust** que integra detección de objetos, estimación de profundidad y seguimiento de múltiples personas a través de filtros de Kalman. El núcleo del software utiliza un **motor de estados finitos (FSM)** para interpretar comportamientos complejos, permitiendo distinguir eventos específicos como la ocupación de una habitación o la presencia en zonas críticas. Los datos se procesan mediante un sistema de **cascada de modelos**, donde las detecciones primarias activan análisis secundarios de alta resolución para mejorar la precisión. La gestión eficiente de la memoria se logra mediante un **esquema de buffer pooling** y el uso exclusivo de fotogramas clave para reducir la carga computacional. Finalmente, el sistema ofrece **capacidades de observabilidad** avanzadas al integrar registros estructurados y herramientas de visualización en tiempo vivo para el monitoreo de escenas.
