# mana-geometry
La biblioteca **mana-geometry** actúa como un motor de procesamiento espacial optimizado para gestionar datos de visión artificial a través de diversos módulos especializados en **aritmética de cajas delimitadoras** y métricas de superposición. El sistema facilita la conversión fluida entre coordenadas normalizadas y de píxeles, empleando algoritmos de **intersección sobre unión (IoU)** para el seguimiento de entidades y la detección de zonas. Para optimizar el rendimiento, utiliza técnicas de **codificación por longitud de racha (RLE)** que comprimen máscaras de segmentación y aplica el algoritmo de **Ramer-Douglas-Peucker** para simplificar contornos complejos en polígonos eficientes. Finalmente, la infraestructura garantiza la precisión de los datos mediante **transformaciones de coordenadas**, permitiendo que las detecciones realizadas en modelos escalados se mapeen correctamente de vuelta a las dimensiones originales de la imagen.

The `mana-geometry` crate provides a shared library of spatial primitives, bounding box arithmetic, and mask processing utilities used across the inference and control pipelines. It is designed for high-performance execution, often utilizing `const` functions and `Arc`-backed zero-copy sharing for large mask data.

## 1. Bounding Box Arithmetic (`bbox`)

The system primarily operates in two coordinate spaces: **Normalized** (0.0 to 1.0 relative to frame size) and **Pixel** (absolute coordinates). The `bbox` module provides standard conversions and manipulations for these formats.

### Core Functions

|Function|Description|
|---|---|
|`center_to_corners`|Converts `(cx, cy, w, h)` to `(x1, y1, x2, y2)`. [[std/mana-geometry/src/bbox.rs:8-10]](7.1-mana-geometry)|
|`corners_to_center`|Converts `(x1, y1, x2, y2)` to `(cx, cy, w, h)`. [[std/mana-geometry/src/bbox.rs:14-16]](7.1-mana-geometry)|
|`xyxy_to_xcycarh`|Converts to `(cx, cy, aspect_ratio, height)`, the format required by the Kalman filter. [[std/mana-geometry/src/bbox.rs:95-102]](7.1-mana-geometry)|
|`clamp_box`|Ensures a box stays within `[0, 1]` by shrinking dimensions if the center is too close to an edge. [[std/mana-geometry/src/bbox.rs:117-123]](7.1-mana-geometry)|
|`pad_boxes_px`|Expands boxes by a specific pixel margin. [[std/mana-geometry/src/bbox.rs:51-59]](7.1-mana-geometry)|

## 2. Intersection over Union (`iou`)

The `iou` module implements overlap metrics used for Non-Maximum Suppression (NMS), entity tracking association, and zone occupancy detection.

### Overlap Metrics

The system supports two primary metrics via the `OverlapMetric` enum [[std/mana-geometry/src/iou.rs:7-11]](7.1-mana-geometry):

1. **IoU (Intersection over Union):** Standard metric for detection merging and tracking.
2. **IoS (Intersection over Smallest):** Used when checking if one detection (e.g., a face) is entirely contained within another (e.g., a person).

### Key Implementation

- **`box_overlap`**: Computes the overlap between two corner-format boxes based on the selected metric. [[std/mana-geometry/src/iou.rs:18-38]](7.1-mana-geometry)
- **`box_overlap_batch`**: Generates a row-major flat matrix of overlaps between two sets of boxes, typically used during Hungarian association in the tracker. [[std/mana-geometry/src/iou.rs:46-61]](7.1-mana-geometry)
- **`with_zone`**: Specialized IoU calculation between a detection and a static `Zone` definition. [[std/mana-geometry/src/iou.rs:66-97]](7.1-mana-geometry)

**Sources:** [[std/mana-geometry/src/iou.rs:1-97]](7.1-mana-geometry)

## 3. Compact Mask Storage (`CompactMask`)

`CompactMask` is a specialized container for segmentation masks. Instead of storing a full-frame bitmask (which is memory-intensive), it stores a **Column-Major Run-Length Encoded (RLE)** representation scoped to the detection's bounding box.

### Data Layout

The `CompactMask` struct uses `Arc<[u32]>` (via the `vernier-mask` crate's `Rle` type) to allow zero-copy sharing of mask data between the `InferEngine` and the `LogManager`.

- **`rles`**: A vector of RLE encoded masks. [[std/mana-geometry/src/compact_mask.rs:66]](7.1-mana-geometry)
- **`offsets`**: The `(x1, y1)` pixel coordinates of each mask's bounding box relative to the full image. [[std/mana-geometry/src/compact_mask.rs:67]](7.1-mana-geometry)
- **`image_shape`**: The `(height, width)` of the source image. [[std/mana-geometry/src/compact_mask.rs:68]](7.1-mana-geometry)

## 4. Polygonization and Simplification

The `polygonize` module converts binary masks into simplified vector contours. This is used to reduce the data footprint for UI rendering and complex spatial queries.

### Process Flow

1. **Contour Detection**: Uses Suzuki-Abe border following via `imageproc::contours::find_contours`. [[std/mana-geometry/src/polygonize.rs:64-67]](7.1-mana-geometry)
2. **Simplification**: Applies the **Ramer-Douglas-Peucker (RDP)** algorithm to reduce the number of vertices while maintaining the shape's integrity. [[std/mana-geometry/src/polygonize.rs:93]](7.1-mana-geometry)
3. **Validation**: Filters polygons by area using the **Shoelace formula** to remove noise or small disconnected components. [[std/mana-geometry/src/polygonize.rs:99-110]](7.1-mana-geometry)

### Polygon Operations

- **`polygon_center`**: Calculates the signed-area weighted centroid. [[std/mana-geometry/src/polygon.rs:10-45]](7.1-mana-geometry)
- **`polygon_area`**: Computes the absolute Shoelace area. [[std/mana-geometry/src/polygon.rs:48-61]](7.1-mana-geometry)
- **`filter_small_components`**: A pre-polygonization pass that removes 8-connected foreground clusters below a specific area threshold. [[std/mana-geometry/src/polygonize.rs:131-195]](7.1-mana-geometry)

**Sources:** [[std/mana-geometry/src/polygonize.rs:1-122]](7.1-mana-geometry), [[std/mana-geometry/src/polygon.rs:1-84]](7.1-mana-geometry)

## 5. Coordinate Transforms (`Transform`)

During inference, images are typically resized and padded (letterboxed) to fit model requirements. The `Transform` struct stores the parameters necessary to map detections back to the original image coordinates.

### Key Logic

- **`unletterbox`**: The core math function: `(raw_coord - pad) / scale`. [[std/mana-geometry/src/transform.rs:17-19]](7.1-mana-geometry)
