# Archivo documental

Este directorio conserva notas experimentales o referencias reemplazadas que no
son contrato vigente. La documentacion activa vive en:

- `README.md` y `ARCHITECTURE.md` en la raiz;
- `docs/adrs/`;
- `docs/specs/`;
- `workshop/`;
- `docs/subprojects/`.

Un documento archivado no debe usarse para decidir cambios de implementacion sin
compararlo con la spec y los ADRs actuales.
